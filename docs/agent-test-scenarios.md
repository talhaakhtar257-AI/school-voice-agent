# 50 test scenarios for the admissions agent

Every expected answer below comes from the content published on
**2026-09-15**. If the agent says something different, it is not reading your
content — tell Claude and the call logs will show it.

**How to run these:** you do not need 50 calls. Group them 5–6 per call, or use
**Dashboard → Content → Test the draft** for the text-only ones. A call costs
Retell minutes; the text test costs nothing.

**Pass marks used below**
- ✅ the agent gives these figures or facts
- 🤝 the agent must hand over to the office and never answer
- 📝 the agent must say the office will help **and** record the question in the gap list
- 🚫 the agent must refuse

## After the test

1. **Dashboard → Leads:** every enquiry call should have created a row, with the class written exactly as in the content, e.g. "Class 1".
2. **Dashboard → Gap list:** scenarios 7, 40 and 41 should appear there. Answer one from the dashboard, publish, and ask again — the agent should then answer it. This is the best moment in a client demo.
3. Anything the agent got wrong: tell Claude the scenario number, and the logs will show whether it read the content.
